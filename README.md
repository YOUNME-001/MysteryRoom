# 🧩 Project Name: Mystery Room (가제)
> **Genre:** 3D 방탈출 / 서스펜스 / 퍼즐 / 추리

---

## 📌 Overview
이 프로젝트는 한국 원룸을 탈출하는 게임입니다. 
플레이어는 제한된 공간 내에서 단서를 찾고, 물리 기반 퍼즐을 해결하여 탈출해야 합니다.

## 🛠 Tech Stack
- **Engine:** Unity 6000.3.10f1 LTS (Universal Render Pipeline)
- **Language:** C#

## 💻 Installation
1. Clone the repository.
2. Open with Unity Hub (Version 6000.3.10f1 추천).
3. Play `Scenes/MainScene.unity`.
